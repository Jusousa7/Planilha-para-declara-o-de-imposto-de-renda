# Planilha-para-declara-o-de-imposto-de-renda
*Essa planilha foi criada para estudos no curso da DIO.*

A planilha disponível neste repositório foi criada a partir da aulas do curso da DIO, adaptada ao meu estilo visual e com diversas funções.
Na lateral há um menu navegável que ti dirige para as abas de: TITULAR, INFORMES E NOTAS.
Possui botões interativos para melhor navegar entre as abas e na aba de informes um gráfico que informa o valor de cada banco em relação ao total.
